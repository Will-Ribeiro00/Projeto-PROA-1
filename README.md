# 🍰 Minhas Receitas de Doces 🧁

Um projeto simples desenvolvido em **HTML e CSS** para apresentar algumas receitas de doces de forma visual e organizada.

A página inicial permite escolher entre diferentes receitas e acessar uma página específica com os ingredientes e modo de preparo.

## 📋 Receitas disponíveis

- 🧁 **Cupcake de Chocolate**
- 🍫 **Brigadeiro Gourmet**
- 🍮 **Pudim de Leite**
- 🥕 **Bolo de Cenoura**

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
